# دفتر مبيعات الموظفين

تطبيق ويب لتتبّع مبيعات الموظفين بالتفصيل (السعر، النوع، التاريخ) وحساب المكافأة الشهرية تلقائياً، مع قاعدة بيانات مشتركة (Supabase) بحيث يرى الجميع نفس البيانات مباشرة.

## الخطوات

### ١. إنشاء قاعدة بيانات Supabase (مجانية)
1. افتح https://supabase.com وأنشئ حساباً (يمكن الدخول بحساب GitHub أو Google).
2. اضغط **New project**، اختر اسماً وكلمة مرور لقاعدة البيانات، واختر منطقة قريبة منك.
3. بعد إنشاء المشروع، اذهب إلى **SQL Editor** من القائمة الجانبية، ثم **New query**.
4. افتح ملف `schema.sql` الموجود في هذا المجلد، انسخ محتواه بالكامل، الصقه، ثم اضغط **Run**.
5. اذهب إلى **Project Settings > API**. ستجد هناك:
   - **Project URL**
   - **anon public key**
   احتفظ بهما، ستحتاجهما في الخطوة التالية.

### ٢. ضبط بيانات الاتصال محلياً
1. انسخ ملف `.env.example` وأعد تسميته إلى `.env`.
2. افتح `.env` وضع فيه القيم التي حصلت عليها من Supabase:
   ```
   VITE_SUPABASE_URL=https://xxxxx.supabase.co
   VITE_SUPABASE_ANON_KEY=xxxxxxxxxxxxxxxx
   ```

### ٣. التجربة محلياً (اختياري)
يتطلب تثبيت Node.js على جهازك من https://nodejs.org
```
npm install
npm run dev
```
سيفتح الموقع على `http://localhost:5173`

### ٤. النشر على الإنترنت عبر Vercel
1. أنشئ مستودعاً على GitHub وارفع هذا المجلد إليه (أو استخدم واجهة GitHub لرفع الملفات مباشرة بدون سطر أوامر: "Add file > Upload files").
2. افتح https://vercel.com وسجّل دخول (يفضّل بحساب GitHub نفسه).
3. اضغط **Add New > Project**، واختر المستودع الذي رفعته.
4. في خطوة الإعدادات، افتح **Environment Variables** وأضف نفس القيمتين من ملف `.env`:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`
5. اضغط **Deploy** وانتظر دقيقة تقريباً.
6. بعد الانتهاء، سيعطيك Vercel رابطاً دائماً (مثل `sales-ledger.vercel.app`) — هذا هو الرابط الذي ترسله لموظفيك.

## ملاحظة عن الخصوصية
حالياً أي شخص يملك الرابط يمكنه إدخال أو حذف البيانات (لا يوجد تسجيل دخول منفصل لكل موظف). هذا مناسب كأداة داخلية بسيطة. إذا أردت لاحقاً أن يكون لكل موظف حساب خاص يرى فيه مبيعاته فقط، يمكن إضافة نظام تسجيل دخول (Supabase Auth) — أخبرني إن احتجت ذلك.
